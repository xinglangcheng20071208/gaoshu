# 高数刷题营 · 大一上学期

一个响应式多端兼容的高数刷题网站，覆盖大一上学期全部章节，每天自动生成 10 道练习题，并按你的掌握程度智能安排复习。

## 打开方式

方式一（推荐）：在项目目录启动本地服务器后访问 `http://127.0.0.1:8123/`
```
python -m http.server 8123
```

方式二：直接用浏览器打开 `index.html`（功能完整可用；公式渲染需要联网加载 KaTeX，断网时自动切换内置的简易公式渲染器，不影响刷题）

## 📱 手机访问（不走局域网）

- **公网地址（任何网络都能开，含手机流量）**：运行 `tools\cloudflared.exe tunnel --no-autoupdate --url http://127.0.0.1:8123` 后，访问输出中给出的 `https://xxx.trycloudflare.com` 地址；`shots\phone-qr.png` 是配套二维码。
  - 注意：电脑需保持开机且隧道进程运行；免费快速隧道每次重启地址会变、无稳定运行保证。
- **局域网地址（手机与电脑连同一 Wi-Fi）**：电脑以 `0.0.0.0` 启动服务器（`python -m http.server 8123 --bind 0.0.0.0`），手机访问 `http://<电脑IP>:8123/`。
- 提醒：做题记录保存在**各自设备的浏览器**里（localStorage），手机和电脑的记录互不相通；若要跨设备同步或固定域名，需要部署到静态托管（如 GitHub Pages），可另行配置。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 双板块 | 顶部可在**高数**与**北京高考**之间切换（也支持链接 `?track=gaokao` 直接打开高考板块），两套题库、错题本、记录、掌握度互不干扰 |
| 每日 10 题 | 每天自动生成 10 道题（同一天内保持同一套，跨天自动换新；跨天自动避开上次原题） |
| 北京高考 · 卷面题型 | 按北京卷卷面题型分为**选择题 / 填空题 / 解答题**；每日 10 题按 6 选择 + 3 填空 + 1 解答的卷面配比生成，每题带知识模块标签（集合、复数、函数导数、三角、数列、向量、不等式、立体几何、解析几何、概率统计） |
| 学期选择 | 高数板块可切换**大一上 / 大一下**：大一上（一元微积分）7 章；大一下（向量、多元微分、重积分、三重积分、曲线积分、级数、二阶方程）7 章，每日练习与专项练习都按所选学期组卷 |
| 每日自选题型 | 每日练习顶部可**混搭勾选**想练的章节（不选=本学期全部），选择后按新题型重新组卷并尊重复习节奏 |
| 题型形式自由搭配 | 高数今日练习**和**专项练习都可勾选「选择题 / 解答题 / 证明题」任意组合；只选解答/证明时不会混入选择题（没有该形式的章节会用另一种笔答题兜底） |
| 填空题作答 | 高考填空题可直接在输入框作答，支持数字、分数、区间等写法（回车提交），自动判对错并展示解析 |
| 解答/证明题 | 题库含 **19 道解答/证明题**（高数）+ **7 道高考解答题**：只给题目、没有选项，点「✓ 已完成」后展示参考答案 + 思路 + 分步过程 + 易错点（不参与客观题正确率统计） |
| 三级难度 | 基础 / 进阶 / 困难，随时切换，覆盖全部章节 |
| 专项练习 | 自定义勾选题型（可多选）、题型形式、难度（基础/进阶/困难/混合）、题量（5/10/15/20），生成专项套题 |
| 掌握度标记 | 每道题上方有「已掌握 / 不熟练 / 未掌握」三个选项 |
| 智能复习节奏 | 已掌握 → 7 天后出类似题；不熟练 → **1 天后**出类似题；未掌握 → 连续 2 天出类似题 |
| 错题本 | 自动收录「答错 / 不熟练 / 未掌握」的题（含专项练习），标记「已掌握」自动移出 |
| 错题重做（举一反三） | 错题本可**勾选多选**，点「重做所选」按**同题型换数字**出变式新题（绝不原题重复）；重做**做对**的题会盖 ✅已订正 标记并保留在错题本 |
| 做题记录 | 累计做题数、正确率、连续学习天数、每章正确率、历史明细（标注每日/专项/错题重做来源） |
| 掌握度总览 | 每个章节的状态、正确率、下次复习日期 |
| 解题思路与过程 | 每题附思路 + 分步过程（每一步都有大白话解释）+ 易错点，新手友好 |
| 技法标签 | 题目上方显示本题考察的方法标签（等价无穷小/凑微分/分部积分/奇偶性…），一眼知道考什么 |
| 深色模式 | 右上角一键切换，自动记忆 |
| 数据本地保存 | 全部数据存于本机浏览器 localStorage，断网可用 |
| 数据备份与云同步 | 支持**导出 / 导入 / 合并导入** JSON 备份，每天自动快照（保留 3 天，可一键恢复）；换设备不丢数据（云同步方案见 IMPROVEMENTS.md） |
| 离线可用 | **自托管 KaTeX**（不依赖 CDN）+ Service Worker 缓存，首次访问后断网也能打开并正常显示公式 |
| 学习成就 | 8 个成就徽章（连续打卡 / 百题 / 掌握章节 / 正确率）+ 正确率环形图、章节条形图、30 天打卡热力图、14 天趋势 |
| 跟课刷题 | 今日练习页一键生成「当前章节」10 题，直接进入专项练习 |
| 举一反三差异 | 错题重做时展示"变式差异"（原题参数 → 新题参数），明确知道改了什么 |
| 分享海报 | 一键生成 720×1000 学习海报 PNG（累计题数/正确率/连续打卡/掌握章节）+ 复制分享文案 |

## 题库扩充来源（例题拆分 + 标签归类）

题库在经典题库模板基础上，持续从公开教学例题中吸纳题型：按"**每一小题**"拆分为独立题型；原题自带章节标签的直接沿用（映射到 7 个章节），无标签的由模型分析其考察知识点后归类，并打上技法标签。示例：

| 公开例题类型 | 归类标签（章节/技法） | 对应模板 |
| --- | --- | --- |
| $\lim \frac{\tan ax}{\sin bx}$ | 极限 / 等价无穷小 | limit-L18 |
| $\sqrt{x^2+ax}-x$ 求极限 | 极限 / 有理化 | limit-L20 |
| $\frac{\sin x-x}{x^3}$ | 极限 / 洛必达·泰勒 | limit-L22 |
| 隐函数 $x^2+xy+y^2=3$ 求 $y'$ | 导数 / 隐函数求导 | derivative-D18 |
| 切线方程 $y=x^2$ 在 $x=a$ | 导数 / 切线方程 | derivative-D17 |
| $\int x\sqrt{x^2+a}dx$ | 不定积分 / 凑微分 | indint-I19 |
| $\int \frac{e^{\sqrt x}}{\sqrt x}dx$ | 不定积分 / 换元法 | indint-I20 |
| $\int x^2e^x dx$ | 不定积分 / 分部积分 | indint-I22 |
| $\int_0^{\pi/2}\sin^2x\,dx$ | 定积分 / 降幂积分 | defint-Df18 |
| $\sqrt{x}$ 与 $x$ 围成面积 | 积分应用 / 两曲线面积 | defapp-Ap13 |
| $\sin x$ 绕 $x$ 轴体积 | 积分应用 / 旋转体体积 | defapp-Ap14 |
| $y'=2xy,\ y(0)=1$ | 微分方程 / 分离变量 | ode-O15 |

## 题目如何保证正确

- 题库共 **209 个题型模板**（高数 177 + 北京高考 32，含 26 道解答/证明题），每道题由程序**即时生成**（参数随机化），答案是**由参数计算出来的**，不是手抄的；
- 同类题可无限生成（"类似题目"就是同模板换参数）；
- 出题带"举一反三"去重：每道题有唯一标签（模板+参数），每日/专项组卷会避开本套内与上次做过的原题；错题重做则从原错题的同模板换参数出变式题，保证"同题型、不同题"；
- 自带自测脚本，见下方「自测」。
